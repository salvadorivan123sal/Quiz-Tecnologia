# Quiz-Tecnologia

# Descripción:

Es un juego de preguntas y respuestas sobre Tecnología enfocado en hardware y software de una computadora, fue hecho en python con interfaz gráfica hecha con Tkinter. El jugador responde preguntas de dificultad variable referentes al tema. Cada acierto le suma al jugador un punto y cada fallo una vida de las 3 que tiene. El juego termina si el jugador ya no tiene mas vidas o termina con las preguntas, mostrando en pantalla sus resultados.

# Cómo ejecutarlo:
1. Necesita python instalado en la computadora. 
2. Clonar este repositorio o descargar los archivos.
3. Abrir una terminal dentro de la carpeta del proyecto y ejecuta:
    -python quiz_tecnologia.py
